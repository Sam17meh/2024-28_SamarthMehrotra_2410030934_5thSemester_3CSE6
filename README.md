## Project Summary

The NetSage AI problem statement asked for an AI-assisted troubleshooting helper for Cisco Packet Tracer lab exercises. The system takes a student's description of symptoms along with relevant `show` command output, analyzes them using an AI reasoning layer, and returns ranked likely causes with suggested next steps. Every suggestion requires explicit human review and approval before it is treated as final — the system never applies a fix automatically.
